## 系统性整改

关键发布输入统一进入 `fillAndCommitLocator`：可见定位、滚动、聚焦、清空、Playwright `fill`、Tab/Enter 提交以及精确 `inputValue` 回读。基础信息、价格库存、平台 SPU 查询与保健食品规格数量不再直接调用原生 value setter、伪造 InputEvent/change 或操作 React 私有 value tracker。

登录边界继续采用合规的失败关闭语义：每个发布目标都通过店铺/发布页登录检查；扫码或平台验证出现时停止副作用、保留精确断点并等待人工恢复。项目不实现验证码绕过、浏览器指纹伪装、风控规避或不确定提交自动重放。
