# 规格模板选项误判根因与闭环（2026-08-20）

## 真实故障证据

运行 `20260819-234927` 的 `publish-page-spec-editor.png` 显示，规格模板下拉框确实包含 `买一送一`，同一选项行还显示 `更新时间：2026/08/19 10:34:34`。旧动作把整行文本与飞书值做相等比较，因此把 `买一送一 + 更新时间` 错判为没有精确选项。

## 工程整改

| 要求 | 规则层 | 动作层 | 验证 |
| --- | --- | --- | --- |
| 飞书值必须精确选择 | `resolveExactSpecTemplateOptionMatch` 只接受选项首行语义标签与飞书值完全一致 | 收集可见选项行并交给规则层裁决 | `scripts/test-spec-template-rule.mjs` 覆盖带更新时间的真实结构 |
| 不得把相似模板当成目标 | `粉丝专享买一送一` 不等于 `买一送一` | 只点击规则层返回的唯一标记行 | 负向回归测试 |
| 异步下拉稳定可用 | 多个精确匹配 fail closed | 选项行按真实可点击节点去重，并等待门户挂载 | build、规则检查、真实续跑 |
| 真缺失才通知 Hermes | 无精确语义标签才返回缺失 | 保留原有停止与 `没有对应的规格模板可选` 状态链路 | 状态规则回归 |

该整改不放宽飞书值的精确匹配，也不修改平台模板内容。
