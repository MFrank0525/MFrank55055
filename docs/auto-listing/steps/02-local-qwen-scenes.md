# 步骤 02：本地千问商品场景规划

## 目标

把步骤 01 已审核并固化的商品文案交给本机 Ollama `qwen3.6:35b-a3b`，先识别商品名称、主标题和副标题共同指向的核心用户任务，再生成 5 个互不重复、能够解释真实购买动机的消费场景。外部网页不得参与场景规划；包装事实、海报文案、艺术字差异化和质量门禁仍由程序控制。

## 动作与规则

- [qwen-scene-planner.ts](../../../src/autolist/qwen-scene-planner.ts)
- [scene-word-docs.ts](../../../src/autolist/scene-word-docs.ts)

## 唯一语义来源

### 来源规则

商品名称与语义只来自当前飞书记录。可展示主标题、副标题和卖点的唯一来源是飞书 `主图主标题`、`主图副标题`、`主图卖点` 经步骤 01 审核并固化的完整商品文案；场景规划固定使用本地 `qwen3.6:35b-a3b`。千问不得查看商品图片、猜测包装、改写文案或新增功效、适用人群、成分、认证、规格及品牌口号。

## 本地模型契约

类目提示词数量是固定业务规则：

- 医疗器械：5 段提示词。
- 非处方药：5 段提示词。
- 保健食品：5 段提示词。

1. 唯一模型为本地 `qwen3.6:35b-a3b`，默认地址 `http://127.0.0.1:11434`。
2. 请求使用 Ollama `/api/generate`、`stream=false`、`think=false` 和固定 JSON schema。
3. 返回值必须恰好包含 5 个对象；每个对象只有 `locationConcept`、`userNeed`、`consumerMoment`、`environment`、`mood`、`interaction` 六个字段。`locationConcept` 只能来自程序固定枚举，结构或内容越界时本地最多纠错重试三次，仍不合格则失败关闭。
4. 五个场景的地点类别、消费者时刻、环境和互动方式必须各不相同；中文地点必须与 `locationConcept` 精确归一到同一类别，沙滩、海边和海滩统一视为 `beach`。
5. 五个 `userNeed` 必须服务同一个核心用户任务；核心卖点只能作为选择理由，不能被机械拆成五种用途。产品特征、成分、技术、器械等级、无菌或官方正品不得冒充用户需求。
6. 出现医院医生、症状伤口、治疗结果、前后对比、未批准人群、其他商品、促销信息、抽象功效外推或新增可读文字时整组失败，不进入付费生图。

## 程序边界

程序把千问六字段组装为 5 个有边界的场景段落。人物、手部、使用部位、纯商品、步骤、原理、配色、光线和道具都不是必选模板，只能在有助于解释当前用户需求和消费时刻时使用。20 张图片的差异化由真实场景、四种构图和 20 套艺术字共同形成，不得用固定“临床/生活/科技/纯商品/步骤”角色覆盖场景。

每个场景段落都必须再次锁定：完整参考商品组原样、成组、清晰可识别；包装数量、文字、比例、颜色和标识只以参考图为准；禁止症状、医院、治疗结果、前后对比、其他商品、促销元素和额外可读文字。商品、人物与环境的相对大小由当前需求决定，不使用固定面积比例硬套。

## Word 输出

每份 Word 只能包含两段：

```text
第一段：已审核的完整商品文案
第二段：当前轮经过程序边界组装的本地千问场景
```

五份 Word、场景规划模型版本、商品文案摘要和业务规则指纹必须绑定。任一摘要或版本变化后，旧场景、旧 Word、旧付费槽位和旧恢复产物不得静默复用。

## 失败条件

- 本地 Ollama 不可访问或未安装指定模型。
- JSON schema 不满足、字段为空、字段过长或不是恰好 5 个场景。
- 五个场景重复。
- `locationConcept` 缺失、越界、与中文地点不一致，或五个场景复用同一地点类别。
- 用户需求没有锚定商品名称、主标题和副标题所表达的核心任务。
- 把卖点、成分、技术、资质或正品证明误当成新的用户任务。
- 场景越过程序内容边界。
- 场景摘要与当前飞书商品文案不一致。
- Word 不是恰好两段或混入旧场景。

以上任一情况均在付费生图前失败关闭。
