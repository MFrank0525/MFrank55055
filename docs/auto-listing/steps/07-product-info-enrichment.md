# 步骤 07：商品信息回填

## 目标

从当前锁定批次的飞书产品记录回填每个产品图片文件夹内标题表格所需的商品信息。

## 动作脚本

- [metadata.ts](src/autolist/metadata.ts)

## 输入

- 当前 task 绑定的飞书产品记录（来源为 `data/feishu/products.json`）
- 产品图片文件夹中的标题表格

## 输出

- 已回填的标题表格

## 操作说明

### 必须回填的字段

```text
导购短标题
品牌
SPU信息
```

### 执行原则

```text
一定要按照当前飞书记录里的信息执行，包括标题、导购短标题、品牌信息、SPU信息等，不要盲目猜测，也不得读取历史商品信息 Excel 或名称映射。
```

## 执行要求

1. 必须严格按照当前 task 绑定且 `recordId` 一致的飞书记录执行。
2. 不允许程序自行猜测、替换、推导或自动选相近值。
3. `导购短标题`、`品牌`、`SPU信息` 任一为空都必须立即失败。
4. 不允许回退到历史商品信息 Excel、名称映射或模糊匹配。

## 失败条件

- 当前 task 缺少对应飞书产品记录或身份不一致
- 回填字段有空值
- 程序试图用猜测值代替表格值

## 人工检查点

1. 打开任意一个产品文件夹里的标题表格，确认已写入导购短标题、品牌、SPU信息。
2. 核对回填值是否与当前飞书产品记录一致。
